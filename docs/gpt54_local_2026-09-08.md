# Full GPT-5.4 local experiment

The user selected full GPT-5.4. The public Hugging Face Space is not changed.

This page records the original **v6** experiment. For the later painting diagnosis,
targeted v7 fixes and fresh four-case results, see

## Configuration

```text
VLM_BACKEND=openai
VLM_MODEL=gpt-5.4-2026-03-05
VLM_PROMPT_PROFILE=structured
```

The adapter pins the exact API snapshot and rejects a different reported model.
It uses Chat Completions, `reasoning_effort=none`, `temperature=0`, standard service
tier, `store=false`, and the existing strict JSON Schema path. There is no model
fallback. All roles use the selected model; per-role model routing is not added.

The structured-v6 prompts, retrieval logic, evidence representation and verification
policy are unchanged. The structured input allowance remains 65,536, with the same
18-image, 1,600-output-token, prompt-size, request-size, timeout and retry guards.
Plain requests retain the existing 32,768 allowance. These are conservative app
limits, not the provider's advertised context/output limits. Cache identity includes
the model and prompt version, so GPT-4.1 mini captions are not silently reused.

Official OpenAI documentation confirms the pinned snapshot, image input and strict
structured-output support. `temperature` is supported when reasoning is `none`.
For `detail=high`, GPT-5.4 uses 32px patches at a 1.2 multiplier without enlarging
small images: at most about 360 image tokens for our 640x480 maximum, or 231 for
the structured pipeline's 512x384 frames. The existing 600-token/frame admission
allowance is retained rather than changing evidence selection or resolution.

## Evaluation scope

Four current library examples: NExT-QA sofa and tree, EgoSchema kitchen and painting.
These are exposed development examples, not a held-out accuracy benchmark. The new
run starts from video files with cold scene caches, including fresh captioning,
retrieval and visual inspection. Reference labels are scorer-only inputs.

The isolated local run has a $2 ceiling, at most 100 HTTP attempts total and 25 per
case, with $0.19 conservatively reserved before each attempt. Standard token rates
are $2.50 / million input, $0.25 / million cached input and $15 / million output.
Unknown charges retain their reservation. This controls the evaluation's ledger,
not unrelated account spending or an OpenAI account-wide billing cap.

Historical evaluations and their artifacts are preserved. A model change alone is
not evidence of improved quality; outcomes, errors, elapsed time and reported token
cost must be inspected before any publication decision.

All four reached matching completed answers and reviews, with no abstentions or
terminal contract errors. There were no semantic answer revisions. Painting needed
one planner contract repair: representative whole-video needs were incorrectly
made dependent; the second planner output satisfied the existing independence rule.
The other three cases needed no format/contract repairs.

There were 61 HTTP attempts, all HTTP 200, using the requested snapshot. Total
reported-usage-based cost was **$0.5154675**, with no outstanding or ambiguous
reservations. Timings include media preparation and cold indexing, using two local
workers; the QA portion is not a separately measured warm-cache user run.

### Sofa: coherent purpose inference, no abstention

The new plan/tool sequence located the earlier sofa/present anchor and traversed
forward, selecting scenes 1/2/3 (about 18–72s). Its Answer connects observed claims
about carrying/handling the present and lifting wrapping/paper to an explicit
inferred conclusion: moving to the sofa to unwrap it. The preliminary choice and
final choice agree, and review accepts both the conclusion and its explanation.
The unrelated sofa-people need remains unaddressed without blocking that answer.

This is structurally more coherent than the previous saved mini replay, which
abstained using frozen 54–90s observations. It is **not a controlled paired model
comparison**: the previous v6 replay did not regenerate captioning, retrieval or
inspection. The new traces also retain some uncertainty about item/paper identity;
successful model review is not independent proof that every visual claim is true.

### Painting: incorrect choice accepted by review

The official answer is **"To clean the paintbrush."** The model instead inferred a
general water-source role from the painting setup, while its own observations say
brush/cup contact is not visible. The reviewer accepted that inference but demanded
visible brush/cup interaction for the cleaning alternative. The resulting answer
is internally linked and schema-valid, but does not distinguish the options
reliably. The larger model therefore has not eliminated mistaken verification.

These four exposed examples yield 4/4 completion and 3/4 accuracy; that small result
does not establish the requested held-out release thresholds. The all-four-correct
library gate failed (runner exit 1), so **nothing was published**. No failed example
was rerun, and prompts were not changed after seeing these results.

Offline verification: 60 focused GPT-5.4 adapter/runtime/runner tests passed,
alongside 225 existing adapter/transport regressions; Ruff passed. The adapter
and runner also received independent read-only review. OpenAI Docs informed the
snapshot, parameter compatibility, and conservative image/pricing accounting.

Post-run read-only audit matched all 61 reconstructed request/image hashes, exact
requested/reported model IDs, v6 final pairs, source snapshots, and SQLite ledger
entries. Reported usage was 142,605 input tokens and 10,597 output tokens, including
zero cached input tokens and zero reasoning tokens. Historical controls remained
unchanged. No additional inference was used for this audit.
